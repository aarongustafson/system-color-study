Submit reviewed results to the study

Export JSON and review its metadata and Notes first. Upload the JSON to GitHub, choose a new branch, and open a pull request. GitHub may ask you to sign in or create a fork.

With a local checkout, write access, and an authenticated GitHub CLI, npm run submit -- /path/to/capture.json validates the file and opens a PR automatically. Use --dry-run to check it without sending anything. Never enter access tokens on this page.
